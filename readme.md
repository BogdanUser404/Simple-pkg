##Simple PKG
Simple PKG is a frontend for managing packages from the AUR, Flatpack, and Pacman repositories from a single utility.

###Flags:
```-install package``` install package
```-remove package``` remove packages
```-update``` Update all packages
```-set-flatpak repository-name URL``` adds the Flatpak repository
